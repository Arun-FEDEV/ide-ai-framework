# Skill: Performance Review

Use for latency, throughput, memory, rendering, query, bundle, or repeated-work concerns.

## Review Focus

- Hot loops and repeated expensive work
- N+1 queries or avoidable database round trips
- Render churn and avoidable re-renders
- Blocking I/O on request or UI paths
- Excessive allocations or unbounded caches
- Large bundles or eager loading

Prefer measurable verification. Explain expected user or operational impact.

# Skill: QA Session

Use when the user reports bugs conversationally or wants to run a bug bash.

## Workflow

1. Capture the observed problem in user language.
2. Clarify reproduction steps and expected behavior.
3. Inspect the codebase for relevant context.
4. Draft durable issue text or a focused fix plan.
5. Ask approval before GitHub mutations.

Prefer clear bug reports over premature fixes when evidence is incomplete.

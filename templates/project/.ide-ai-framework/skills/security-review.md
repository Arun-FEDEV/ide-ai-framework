# Skill: Security Review

Use for auth, permissions, trust boundaries, secrets, injection, SSRF, unsafe side effects, and external input handling.

## Review Focus

- Authentication and authorization bypasses
- Overly broad permissions
- Secret exposure
- Injection risks
- Unsafe redirects or SSRF
- Webhook validation
- Dangerous defaults
- Cross-tenant or cross-user data exposure

Report concrete issues with evidence. Separate proven issues from hypotheses.

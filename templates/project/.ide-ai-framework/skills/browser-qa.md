# Skill: Browser QA

Use for local web app verification, screenshots, UI regressions, and browser-driven proof.

## Workflow

1. Start or identify the local dev server.
2. Open the target route.
3. Verify the core workflow interactively.
4. Capture screenshots or observations.
5. Report exact viewport, route, and remaining manual checks.

Use automated browser checks where available, but be clear when verification was manual.

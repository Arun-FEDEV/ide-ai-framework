# Skill: Project Pitfalls

Use when a project maintains local notes about historical mistakes, fragile areas, or operational gotchas.

## Workflow

1. Look for project-local pitfall docs such as `docs/pitfalls`, `thoughts/shared/pitfalls`, or maintainer-provided notes.
2. Read only relevant notes before risky work.
3. Summarize applicable pitfalls in the plan.
4. Do not copy private pitfall notes into public artifacts.

This skill is a generic template. Individual projects should maintain their own private pitfall notes.

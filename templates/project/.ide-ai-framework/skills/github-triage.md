# Skill: GitHub Triage

Use to review, label, or prepare GitHub issues.

## Workflow

1. Read the full issue and comments.
2. Inspect relevant code or docs.
3. Recommend category and state labels.
4. Present the recommendation before any mutation.
5. Require explicit approval immediately before labels, comments, closes, issue creation, or PR changes.

## Suggested State Labels

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

Every issue should have one state and one category where possible.
